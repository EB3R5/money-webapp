Set it up

  1. In the SimpleFIN Bridge, connect your banks and create a setup token.
  2. On the box that runs the app, claim it once — the token is single-use and the Access URL it yields is the credential: 
    {{ claim_command }}
    Only the Access URL is printed; nothing else is stored.
  3. Put it in .env as SIMPLEFIN_ACCESS_URL (environment only, never the database — docs/SECURITY.md) and restart both containers.
  4. Come back here: the feed shows as configured, and the jobs process runs the first sync (a {{ schedule.lookback_days }}-day lookback) about 20 seconds after its start.
